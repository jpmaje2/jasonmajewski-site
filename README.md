# jasonmajewski.com

Portfolio site for Jason Majewski, Creative Director at Cornett.

- `index.html` is the whole site: homepage grid, header/footer, and every project page (each opens as an overlay, addressed as `/#project-name`).
- `media/` holds every image and video. File names are the original Cargo media IDs.
- `_redirects` sends old Cargo page URLs (e.g. `/natural-light-treadmower`) to the matching project.
- `cargo-export/` is an archive of the original Cargo site data (Nov 2026), kept as a backup.

Hosted on Netlify. Every push to `main` publishes automatically.
